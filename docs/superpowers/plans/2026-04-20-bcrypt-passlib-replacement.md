# Replace passlib with direct bcrypt — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Commit policy for this user:** never run `git commit` without explicit per-commit approval. The "Commit" steps below are *prepare-and-ask* — stage the files, then ask the user before running the commit command.

**Goal:** Drop the unmaintained `passlib` library, swap to direct `bcrypt` (>=5.0,<6), keep every existing hashed password verifying unchanged, and preserve the `AuthService` wrapper API so no call sites outside the auth layer need to change.

**Architecture:** Introduce a small stateless module `src/lfx/src/lfx/services/auth/password.py` exposing `hash_password(plain) -> str` and `verify_password(plain, hashed) -> bool` backed by direct `bcrypt`. Delete the `pwd_context: CryptContext` attribute from `AuthSettings`. Re-target the two `AuthService` wrappers (`get_password_hash`, `verify_password`) at the new module functions. No data migration required — `passlib.CryptContext(schemes=["bcrypt"])` and `bcrypt.hashpw` produce byte-identical `$2b$12$...` hashes.

**Tech Stack:** Python ≥3.10, `bcrypt>=5.0,<6`, `pytest`, `uv` for dependency management.

**Reference spec:** `docs/superpowers/specs/2026-04-20-bcrypt-passlib-replacement-design.md`

```python
"""Password hashing helpers backed by direct bcrypt.

Replaces the prior passlib.CryptContext-based implementation. Hashes produced
here are byte-compatible with passlib's bcrypt scheme — every legacy `$2b$`
hash in the database verifies unchanged.

bcrypt truncates inputs at 72 bytes at the algorithm level. Both passlib and
direct bcrypt inherit this behavior identically — no user-visible change.
"""

from __future__ import annotations

import bcrypt


def hash_password(plain: str) -> str:
    """Hash a plaintext password with bcrypt (default cost factor 12)."""
    return bcrypt.hashpw(plain.encode("utf-8"), bcrypt.gensalt()).decode("utf-8")


def verify_password(plain: str, hashed: str) -> bool:
    """Verify a plaintext password against a stored bcrypt hash.

    Accepts `$2a$`, `$2b$`, and `$2y$` variants — every hash produced by
    legacy passlib installs verifies correctly.
    """
    return bcrypt.checkpw(plain.encode("utf-8"), hashed.encode("utf-8"))
```
